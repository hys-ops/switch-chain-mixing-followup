# A sharper fiber comparison for the lazy graph switch chain

A follow-up to [OpenAI’s Theorem 1.1](https://github.com/openai/math/blob/4eaee87548250b2682affda7d05d947c05554bae/preprints/Polynomial-Mixing-of-the-Switch-Chain-for-Every-Graphical-Degree-Sequence-September-25-2026/main.pdf), improving the same worst-start quarter-total-variation mixing-time upper bound from 2n⁸ to n⁶. This does not change the proposal rule or the exact sampler.
